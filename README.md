### 🚀 About Me

Software Engineering student from Colombia focused on building reliable desktop and backend applications. Passionate about software architecture, distributed systems and computer architecture. I enjoy creating practical solutions that solve real-world problems.

🔭 &nbsp;I'm currently working on **Building an offline-first Pharmacy POS with electronic invoicing and inventory management for Colombian businesses.**  
🌱 &nbsp;I'm currently learning **High-performance backend architectures, Rust, distributed systems and embedded development.**  
👯 &nbsp;I'm looking to collaborate on **Open-source infrastructure, developer tools, desktop applications and backend services.**  
🤔 &nbsp;I'm looking for help with **Distributed databases, offline synchronization and scalable software architectures.**  
💬 &nbsp;Ask me about **Backend development, desktop applications, software architecture, PostgreSQL, Docker, Tauri and NestJS.**
